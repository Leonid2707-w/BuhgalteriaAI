# План MVP

- [x] Проверить репозиторий и сохранить существующие файлы
- [x] Конфигурация, безопасное логирование и allowlist
- [x] Pydantic-модели финансовых сущностей
- [x] SQLite: черновики, FSM и идемпотентность
- [x] Google Sheets: bootstrap, справочники, операции, долги и аудит
- [x] LLM-парсеры DeepSeek/OpenAI с повторной валидацией
- [x] Транскрипция голосовых сообщений через OpenAI
- [x] Telegram-сценарии: ввод, уточнение, карточка, редактирование, подтверждение
- [x] Управление структурой, балансы, отчёты, долги и undo
- [x] Тесты без внешних API
- [x] PowerShell-скрипты и документация
- [x] Ruff, pytest и проверка запуска

## Ограничения первой версии

- Один Telegram-владелец или небольшой allowlist.
- Одна операция в одном сообщении.
- Курсы валют не пересчитываются, итоги всегда разделены по валютам.
- Исправление подтверждённой операции выполняется через отмену и новую операцию.
